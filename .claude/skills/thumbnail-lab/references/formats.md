# Formats

Ten formats that keep showing up among outliers. Pick two or three per video and make them really different. The column "carries evergreen" says whether the format also wins without news behind the topic.

| Format | What it looks like | Carries evergreen | Fits when |
|---|---|---|---|
| Level columns | 3 to 7 numbered columns, the same figure or object grows stronger left to right | yes, strongest evidence | levels, stages, "every level of X" |
| Big number plus grid | one giant glowing number, a grid of N cards with simple line icons | amplifies, rarely carries alone | "N ways / N patterns", list videos |
| Icon arc | host in the centre, 4 to 6 glossy tiles in an arc around the head | yes when the host is known | "everything about X", feature tours |
| Objects in open hands | host holds two 3D objects, one per palm: old vs new, cheap vs valuable | yes | comparisons, upgrades, "same price, different result" |
| Before / after | split frame, chaos left, order right | yes | transformations |
| Proof screen | real result on a screen, host points at it | yes when the result is real | builds, dashboards, numbers |
| Giant word | one huge word behind or beside the host, brand mark small | with a release | named features, launches |
| Tool equation | two glowing app icons with a plus | mostly trend | new tool combinations, launches |
| Bold claim | one short sentence against common belief, little else | with a strong claim | opinion pieces |
| Interface as message | a familiar toggle or button tells the story | with a known UI | "switch from X to Y" |

## Lessons from a controlled experiment (12 variants, one factor changed each)

- JSON prompt vs prose prompt with identical content: no visible difference in two of three pairs; prose was better in the third because a JSON field was taken too literally.
- Style teardown of a proven reference applied to new content: three of four clearly more premium (big number grid, icon arc, objects in hands). The miss came from a background the schema could not express (a colour gradient became a black/white split). Describe gradients explicitly.
- Headline set in code: exact in 12 of 12. Image-model text was often wrong in earlier runs (case, spacing, letters touching the head).
- Surprised vs laughing expression: surprise read livelier, but skin was flagged as over-sharpened more often.
- Hands presenting objects tend to reach into the bottom-right corner. Ask for hands at chest height, close to the body.
